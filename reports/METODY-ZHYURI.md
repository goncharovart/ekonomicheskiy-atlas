## 2. Шесть индексов ICVI

Обозначения: $N$ — число МО; $K$ — число кластеров $C_1,\dots,C_K$; $x_i$ — вектор признаков МО $i$; $c_k$ — центр кластера $k$; $\bar x$ — общий центр; $A$ — симметричная взвешенная матрица смежности без петель; $m=\tfrac12\sum_{ij}A_{ij}$.

### Сводка

| Индекс | Пространство | Лучше | Диапазон | Первоисточник | Готовая реализация (лицензия) |
|---|---|---|---|---|---|
| SW, силуэт | признаки (или любая матрица расстояний) | больше | $[-1,1]$ | Rousseeuw 1987 | `sklearn.metrics.silhouette_score` (BSD-3) |
| CH, Калински–Харабаш | признаки (евклидово) | больше | $[0,\infty)$ | Caliński, Harabasz 1974 | `sklearn.metrics.calinski_harabasz_score` (BSD-3) |
| S_Dbw | признаки | меньше | $[0,\infty)$ | Halkidi, Vazirgiannis 2001 | пакет [`s-dbw`](https://github.com/alashkov83/S_Dbw) (MIT) |
| AVI | граф | больше | $[0,1]$, у случайного разбиения ≈ $1/K$ | Biswas, Biswas 2017 | [Pattern](https://github.com/Utopialvo/Pattern) (GPL-3.0) или 15 строк из §2.4 |
| AVU | граф | меньше | $\ge 0$ | Biswas, Biswas 2017 | там же |
| MQ = модулярность Q | граф | больше | $[-\tfrac12,1)$ | Newman, Girvan 2004 | `networkx.community.modularity` (BSD-3); Pattern |

### 2.1 SW — силуэт

Для МО $i$ из кластера $C_k$: $a(i)$ — среднее расстояние до своих, $b(i)=\min_{l\ne k}$ среднего расстояния до кластера $C_l$:

$$s(i)=\frac{b(i)-a(i)}{\max\{a(i),b(i)\}},\qquad SW=\frac1N\sum_i s(i).$$

Больше — лучше. У одноэлементного кластера $s(i)=0$.
Источник: Rousseeuw P.J. // J. Comput. Appl. Math. 20 (1987) 53–65, [doi:10.1016/0377-0427(87)90125-7](https://doi.org/10.1016/0377-0427(87)90125-7).
Можно считать и на графе: по матрице расстояний $1-\text{cos}$ с `metric="precomputed"`. Именно этот вариант разбирает свежая работа [When Does the Silhouette Score Work? … in Network Clustering, arXiv:2512.24841](https://arxiv.org/pdf/2512.24841).

### 2.2 CH — индекс Калински–Харабаша

$$CH=\frac{\operatorname{tr}(B)/(K-1)}{\operatorname{tr}(W)/(N-K)},\quad \operatorname{tr}(B)=\sum_k |C_k|\,\|c_k-\bar x\|^2,\quad \operatorname{tr}(W)=\sum_k\sum_{i\in C_k}\|x_i-c_k\|^2.$$

Больше — лучше. Индекс завязан на евклидову геометрию и растёт на сферических кластерах, поэтому подыгрывает k-means. Это надо честно написать в отчёте.
Источник: Caliński T., Harabasz J. // Communications in Statistics 3(1) (1974) 1–27, [doi:10.1080/03610927408827101](https://doi.org/10.1080/03610927408827101).

### 2.3 S_Dbw — разброс плюс плотность между кластерами

$\sigma(\cdot)$ — вектор дисперсий по признакам, $v_k$ — центр кластера $k$:

$$\text{Scat}=\frac1K\sum_k\frac{\|\sigma(C_k)\|}{\|\sigma(X)\|},\qquad \text{stdev}=\frac1K\sqrt{\sum_k\|\sigma(C_k)\|},$$

$$\text{density}(u)=\sum_{x\in C_k\cup C_l}\mathbb 1\big[d(x,u)\le \text{stdev}\big],$$

$$\text{Dens\_bw}=\frac1{K(K-1)}\sum_k\sum_{l\ne k}\frac{\text{density}(u_{kl})}{\max\{\text{density}(v_k),\text{density}(v_l)\}},\qquad u_{kl}=\tfrac12(v_k+v_l),$$

$$S\_Dbw=\text{Scat}+\text{Dens\_bw}\quad(\text{меньше — лучше}).$$

Источник: Halkidi M., Vazirgiannis M. Clustering validity assessment: finding the optimal partitioning of a data set // ICDM 2001, 187–194, [doi:10.1109/ICDM.2001.989517](https://doi.org/10.1109/ICDM.2001.989517). В сравнении Liu et al., ICDM 2010 ([doi:10.1109/ICDM.2010.35](https://doi.org/10.1109/ICDM.2010.35)) S_Dbw признан самым устойчивым из 11 внутренних индексов.
Реализация: `pip install s-dbw` → `S_Dbw(X, labels, method='Halkidi', metric='euclidean')`. В пакете есть варианты (`method='Kim'`, учёт шума DBSCAN), поэтому вариант и версию пакета закрепить в YAML ([репозиторий](https://github.com/alashkov83/S_Dbw), MIT).

### 2.4 AVI — средняя изолированность (Average Isolability)

Введём блочную матрицу связей $S_{ab}=\sum_{i\in C_a}\sum_{j\in C_b}A_{ij}$. Для $a=b$ каждое внутреннее ребро входит дважды. Тогда

$$I_a=\frac{S_{aa}}{\sum_b S_{ab}},\qquad AVI=\frac1K\sum_{a=1}^K I_a .$$

Смысл: доля «веса связей» кластера, который остаётся внутри него. **Больше — лучше.** У случайного разбиения $I_a\approx |C_a|/N$, поэтому $AVI\approx 1/K$.
По выдаче поиска, в статье жюри показано: «AVI растёт с ассортативностью и падает примерно как $1/K$, AVU падает с ростом $K$ до пола, ANUI следует тем же трендам, а у всех индексов при росте перемешивания значения приближаются к случайной базе» ([выдача по статье ESWA 2026](https://doi.org/10.1016/j.eswa.2026.133912); полный текст закрыт, фраза взята из поискового сниппета). Отсюда вывод: сравнивать разбиения с разным $K$ по сырому AVI нельзя (§2.7).

### 2.5 AVU — средняя «слитость» (Average Unifiability) и ANUI

Внешний вес кластера $\text{out}_a=\sum_{b\ne a}S_{ab}$. «Слитость» пары кластеров — доля их общих связей среди всех их внешних связей (аналог коэффициента Жаккара на рёбрах разреза):

$$U_{ab}=\frac{S_{ab}}{\text{out}_a+\text{out}_b-S_{ab}},\qquad AVU=\frac1K\sum_{a}\sum_{b\ne a}U_{ab}.$$

**Меньше — лучше:** кластеры хуже «сливаются» друг с другом.
Сводный индекс ANUI, гармоническое сочетание двух:

$$ANUI=\frac{1}{AVU+1/AVI}=\frac{AVI}{1+AVI\cdot AVU}\quad(\text{больше — лучше}).$$

В коде лаборатории ANUI — основной графовый индекс: он стоит по умолчанию в `GraphMetric` (`pattern/metrics/quality.py`). В критериях конкурса ANUI нет, но посчитать его стоит: это одна строка.

**Нормировка AVU.** В коде Pattern сумма по парам делится на $K$, а не на $K(K-1)$. Первоисточник Biswas & Biswas закрыт (ResearchGate 403), поэтому нормировку автора я не проверил. Решение: берём нормировку лаборатории жюри (это их код) и оговариваем её в отчёте одной фразой.

Проверенный код. Он совпадает с `AdjacencyClusteringMetrics.get_metric` из Pattern и с `networkx` до 1e-9; проверка лежит в scratchpad, `chk_icvi.py`:

```python
def graph_icvi(A, labels):          # A: симметричная (N,N), без петель
    _, y = np.unique(labels, return_inverse=True)
    K = y.max() + 1
    H = np.eye(K)[y]                 # индикаторы N×K
    S = H.T @ A @ H                  # S[a,b] = вес связей между кластерами a и b
    tot, d = S.sum(1), np.diag(S)
    avi = np.divide(d, tot, out=np.zeros(K), where=tot > 0).mean()
    out = tot - d
    den = out[:, None] + out[None, :] - S
    U = np.divide(S, den, out=np.zeros_like(S), where=den > 0); np.fill_diagonal(U, 0)
    avu = U.sum() / K
    anui = 1 / (avu + 1 / avi) if avi > 0 else 0.0
    q = (d / A.sum() - (tot / A.sum()) ** 2).sum()     # модулярность Q (MQ)
    return dict(AVI=avi, AVU=avu, ANUI=anui, MQ=q)
```

Ловушка в коде Pattern: `FeaturesClusteringMetrics` считает центры как `X[clustering == i]` для `i in range(n_clusters)`. Это верно, только если метки идут подряд 0…K−1, поэтому перед вызовом метки надо перенумеровать.

### 2.6 MQ

**Основная версия — модулярность Ньюмана–Гирвана:**

$$Q=\frac1{2m}\sum_{ij}\Big[A_{ij}-\frac{k_ik_j}{2m}\Big]\delta(c_i,c_j)=\sum_{a}\Big[\frac{S_{aa}}{2m}-\Big(\frac{d_a}{2m}\Big)^2\Big],$$

где $k_i$ — взвешенная степень узла, $d_a=\sum_{i\in C_a}k_i$. **Больше — лучше.** Источник: Newman M.E.J., Girvan M. // Phys. Rev. E 69 (2004) 026113, [doi:10.1103/PhysRevE.69.026113](https://doi.org/10.1103/PhysRevE.69.026113). Реализации: `networkx.community.modularity(G, communities, weight="weight")`, метрика `modularity` в Pattern.

**Альтернативное прочтение — Modularization Quality** (Mancoridis et al., IWPC 1998; Mitchell B.S., Mancoridis S. // IEEE TSE 32(3) (2006) 193–208, [doi:10.1109/TSE.2006.31](https://doi.org/10.1109/TSE.2006.31)):

$$MQ=\sum_{a=1}^K CF_a,\qquad CF_a=\frac{2\mu_a}{2\mu_a+\sum_{b\ne a}(\varepsilon_{ab}+\varepsilon_{ba})},$$

где $\mu_a$ — вес рёбер внутри кластера, $\varepsilon_{ab}$ — вес рёбер из $a$ в $b$. На неориентированном графе $2\mu_a=S_{aa}$. Если каждое ребро разреза считать один раз, то $CF_a=I_a$ и $MQ=K\cdot AVI$, то есть это тот же AVI. Поэтому (оценка) в критериях под MQ почти наверняка имеется в виду Q, и ещё один аргумент за это — метрика `modularity` в коде лаборатории. В отчёте дать Q как основной MQ и в сноске показать, что MQ Манкоридиса на нашем графе равен $K\cdot AVI$.
В коде Pattern есть ещё «density modularity», $\sum_a (S_{aa}/2 - d_a^2/4m)/|C_a|$. Её можно дать в приложении.

### 2.7 Как считать честно (это и есть «применение ICVI» на 15%)

1. **Два пространства для всех методов.** SW, CH и S_Dbw считаем в пространстве признаков месяца $t$: стандартизованные доли категорий трат и прочие признаки, одна и та же метрика. AVI, AVU, ANUI и Q — на **одном и том же** графе месяца $t$. Так делали и в статье жюри, где «признаковые и сетевые критерии оценивались на генераторах, в которых атрибуты отвязаны от топологии» ([выдача по статье](https://doi.org/10.1016/j.eswa.2026.133912)). Поэтому таблица «метод × индекс» заполняется целиком, в том числе графовые индексы у k-means и признаковые у Leiden.
2. **Случайная база.** Для каждого разбиения 200 раз перемешиваем метки при тех же размерах кластеров и даём $z=(\text{индекс}-\mu_{\text{перм}})/\sigma_{\text{перм}}$ или разность с базой. Без этого AVI и AVU несравнимы при разных $K$ (§2.4).
3. **Одинаковое $K$.** Основная таблица — при общем $K$ (например, 6, 8 и 10). У Leiden $K$ подбирается параметром разрешения. Отдельно для каждого метода — его лучшее $K$.
4. **Время.** Индексы считаются помесячно и даются рядом по 24 месяцам (медиана и межквартильный размах), а не одним числом.
5. **Сторож на знак.** Юнит-тест: на графе с заведомо изолированными кластерами $AVI\to1$, $AVU\to0$, $Q$ велика; на случайном разбиении $AVI\approx1/K$. Тот же тест ловит неверное направление «больше/меньше».

## 3. Методы членов жюри

### 3.1 Шалилех (и Миркин): кластеризация сетей с атрибутами

Общая модель «восстановления данных» Миркина: признаки $Y$ ($N\times V$) и связи $P$ ($N\times N$) восстанавливаются по разбиению, критерий — сумма квадратов ошибок двух частей с весами $\rho$ (признаки) и $\xi$ или $\zeta$ (сеть).

**SEFNAC.** Кластер $S$ растёт от «опорного» узла. На каждом шаге добавляется узел, который максимизирует вклад кластера в разброс данных (по коду `stage2/stage3`):

$$G(S)=\rho_f\,|S|\,\|c_S\|^2+\rho_g\,\frac{\big(\sum_{i,j\in S}p_{ij}\big)^2}{|S|^2},$$

где $c_S$ — центр кластера в предобработанных признаках, а второе слагаемое равно $\lambda^2|S|^2$ при $\lambda=\sum_{i,j\in S}p_{ij}/|S|^2$. Кластеры выделяются по одному, пока вклад не мал. Отсюда **число кластеров без подбора** — для нас это аргумент в пользу выбранного $K$.

**KEFRiN.** Минимизируется
$$F=\sum_{k=1}^K\sum_{i\in S_k}\Big[\rho\,d(y_i,c_k)+\xi\,d(p_i,\lambda_k)\Big],$$
где $p_i$ — строка матрицы связей, $\lambda_k$ — «сетевой центр» кластера, $d$ — квадрат евклидова, косинусное или манхэттенское расстояние (версии e, c, m). По сути это k-means на склейке признаков и строк смежности. Запуск:
```python
from kefrin import KEFRiNc
labels = KEFRiNc(Y, P, n_clusters=8, rho=1.0, xi=1.0)
```

**CANUS.** Назначение узла в кластер $k^*=\arg\min_k\big[\rho f(x_i,c_k)+\zeta h(a_i,\lambda_k)\big]$, по умолчанию $f,h$ — косинусные. Центры $C\in\mathbb R^{K\times D}$ и $\Lambda\in\mathbb R^{K\times N}$ обновляются градиентным спуском. Фильтр: в обновлении участвуют только узлы, у которых норма градиента лежит в полосе $[\mu-\tau\sigma,\ \mu+\tau\sigma]$, а статистика полосы считается после первого назначения. Всё это — docstring и `CANUSInit` в [canus.py](https://github.com/Sorooshi/CANUS/blob/main/canus.py). Параметры по умолчанию: `epochs=300`, `learning_rate=1e-3`, `tau=1.0`, `rho=zeta=1.0`, `init_mode="kmeans++"`, `update_rule="vanilla_filtered"`, `seed=42`. При $N\approx2000$ матрица $A$ занимает 2000×2000 float32 ≈ 16 МБ, CPU справится.
```python
from canus import CANUSClusterer
m = CANUSClusterer(n_clusters=8, epochs=300, rho=1.0, zeta=1.0, device="cpu").fit(X, A)
labels = m.y_pred
```

**Лицензии.** У CANUS, KEFRiN и SEFNAC файла LICENSE нет, значит по умолчанию «все права защищены». Копировать их код в наш публичный репозиторий нельзя. Делаем так: скрипт `scripts/fetch_jury_methods.sh` клонирует репозитории на закреплённом коммите (CANUS `2025-10-13`) и запускает их, в README ссылка и цитата. Второй вариант — своя реализация по формулам выше: у KEFRiN это 30 строк. Pattern и `leidenalg` под GPL-3.0; если импортировать их как зависимость, проще всего и наш репозиторий выпустить под GPL-3.0.

**Интерпретация «по Миркину»** — её уже использует лаборатория: модуль `visualization/mirkin_analysis.py` в Pattern. Для каждого кластера и признака там считается отклонение центра от общего среднего в сигмах, $(c_{kv}-\bar y_v)/s_v$, и в процентах, $(c_{kv}-\bar y_v)/\bar y_v$. По теории восстановления данных вклад пары «кластер × признак» в объяснённый разброс равен $B_{kv}=|S_k|\,(c_{kv}-\bar y_v)^2$, а его доля — $B_{kv}/T$, где $T=\sum_{i,v}(y_{iv}-\bar y_v)^2$ (Mirkin B. *Clustering: A Data Recovery Approach*, 2nd ed., CRC, 2012). Таблица «кластер × признак» с долями вклада — готовый блок раздела «Интерпретация».

### 3.2 Алескеров: паттерн-анализ

**Понятие.** «Под „паттерном“ в данной работе понимается такая комбинация определённых, с точностью до погрешности, значений некоторого подмножества признаков, что объекты с этими значениями достаточно сильно отличаются от других объектов… [объекты] естественным образом распадаются на группы, придерживающиеся единого паттерна на временном интервале, — так называемые устойчивые группы поведения и менее устойчивые, чередующие паттерны с течением времени». Источник: Алескеров Ф.Т., Белоусова В.Ю., Егорова Л.Г., Миркин Б.Г. Анализ паттернов в статике и динамике, ч. 1 // Бизнес-информатика, 2013, №3(25), с. 3–18, [PDF](https://bijournal.hse.ru/article/download/26193/21894/). Часть 2 с примерами из социально-экономических процессов — там же, №4(26), с. 3–20 ([карточка](https://publications.hse.ru/articles/98648070)).

**Порядково-инвариантная паттерн-кластеризация (OIPC).** Мячин А.Л. (ученик Алескерова): Pattern Analysis in Parallel Coordinates Based on Pairwise Comparison of Parameters // Automation and Remote Control 80(1) (2019) 112–123, [doi:10.1134/S0005117919010107](https://doi.org/10.1134/S0005117919010107); Мячин А.Л. Определение центроидов для повышения точности порядково-инвариантной паттерн-кластеризации // Управление большими системами, 2019, [КиберЛенинка](https://cyberleninka.ru/article/n/opredelenie-tsentroidov-dlya-povysheniya-tochnosti-poryadkovo-invariantnoy-pattern-klasterizatsii).

Для объекта $i$ с нормированными показателями $x_{i1},\dots,x_{in}$ строится верхний треугольник матрицы попарных сравнений:
$$a^{(i)}_{jk}=\begin{cases}\ \text{«>»}, & x_{ij}>x_{ik}\\ \ \text{«=»}, & x_{ij}=x_{ik}\\ \ \text{«<»}, & x_{ij}<x_{ik}\end{cases},\qquad j<k.$$
Два объекта попадают в один кластер тогда и только тогда, когда их матрицы совпадают. Число кластеров заранее не задаётся. Центроид $\bar x_\nu=\frac1{|\nu|}\sum_{i\in\nu}x_i$ всегда лежит в том же паттерне (утверждение 1 у Мячина). Результат не зависит от порядка объектов, кластеры не пересекаются. В параллельных координатах кластер — это пучок ломаных одной формы. Есть и агломеративный вариант, который сливает мелкие паттерны, максимизируя $R^2$ ([выдача по методу](https://link.springer.com/article/10.1134/S0005117919010107)).

**Как применить к помесячным данным МО:**
1. Взять $n=4$–6 ключевых показателей: доли крупных категорий трат, оборот на жителя, индекс мобильности. При строгих неравенствах паттернов не больше $n!$ (720 при $n=6$), иначе кластеров будет больше, чем МО.
2. Нормировать каждый показатель по **всей панели** (все МО × все месяцы): ранг-процентиль или min-max. Тогда паттерн читается как «в чём МО сильнее относительно страны», и паттерны разных месяцев сравнимы.
3. Равенство — с порогом $\varepsilon$: $|x_{ij}-x_{ik}|<\varepsilon$ даёт «=». Порог закрепить в YAML.
4. Для каждого МО получится траектория паттернов $p_i(1),\dots,p_i(24)$. «Устойчивые группы» — МО с одним паттерном весь период, «чередующие» — остальные. Матрица переходов между паттернами, её диагональ — устойчивость.
5. Сравнить OIPC с метрическими кластерами по ARI и NMI и показать, какие паттерны «живут» внутри каждого кластера. Это готовая объясняющая таблица.

**Код:** в открытом доступе не нашёл (поиск GitHub по «ordinal invariant pattern clustering» и «pattern analysis aleskerov» ничего не дал). Реализация умещается в 10 строк: `np.sign(x[:, j] - x[:, k])` по всем парам $j<k$, затем `np.unique(..., axis=0, return_inverse=True)`.

**Агрегирование ранжировок (Алескеров).** Шесть индексов дают шесть ранжировок методов. Свести их в одну можно пороговым агрегированием: Aleskerov F., Yakuba V., Yuzbashev D. A 'threshold aggregation' of three-graded rankings // Mathematical Social Sciences 53(1) (2007) 106–110, [doi:10.1016/j.mathsocsci.2006.09.002](https://doi.org/10.1016/j.mathsocsci.2006.09.002). Каждый индекс ставит методу оценку 1/2/3 (лучшая, средняя или худшая треть), и выше стоит метод с меньшим числом троек, при равенстве — с большим числом единиц. Рядом дать Борда и Коупленда. Итоговая таблица сравнения методов с опорой на работу члена жюри — эта строка попадает в критерий «сравнение методов».

### 3.3 Кузнецов: анализ формальных понятий (FCA)

На странице конкурса — «Сергей Кузнецов, директор Центра языковых и семантических технологий НИУ ВШЭ» ([страница](https://sber.ru/sberindex/konkurs_sberindex)). Это С. О. Кузнецов, один из авторов теории узорных структур в FCA.

**Основа.** Формальный контекст $\mathbb K=(G,M,I)$: $G$ — МО, $M$ — бинарные признаки, $I\subseteq G\times M$. Операторы Галуа:
$$A'=\{m\in M\mid \forall g\in A:\ gIm\},\qquad B'=\{g\in G\mid \forall m\in B:\ gIm\}.$$
Понятие — пара $(A,B)$, у которой $A'=B$ и $B'=A$. $A$ — объём (какие МО), $B$ — содержание (общее описание). Понятия образуют решётку. Источник: Ganter B., Wille R. *Formal Concept Analysis: Mathematical Foundations*, Springer, 1999.

**Устойчивость понятия** (Кузнецов): $\sigma(A,B)=\dfrac{|\{C\subseteq A:\ C'=B\}|}{2^{|A|}}$ — доля подмножеств объёма, которые сохраняют то же описание. Это защита от «случайных» описаний. Kuznetsov S.O. On stability of a formal concept // Annals of Mathematics and Artificial Intelligence 49 (2007) 101–115, [doi:10.1007/s10472-007-9053-6](https://doi.org/10.1007/s10472-007-9053-6). Обзор мер интересности понятий: Kuznetsov S.O., Makhalova T. On interestingness measures of formal concepts // Information Sciences 442–443 (2018) 202–219, [doi:10.1016/j.ins.2018.02.032](https://doi.org/10.1016/j.ins.2018.02.032).

**Узорные структуры для чисел, без бинаризации.** Описание объекта — вектор интервалов, а пересечение описаний — покомпонентная выпуклая оболочка: $[a_1,b_1]\sqcap[a_2,b_2]=[\min(a_1,a_2),\max(b_1,b_2)]$. Понятие тогда читается как «доля продуктов в $[0{,}31;0{,}38]$ и мобильность в $[0{,}9;1{,}1]$». Ganter B., Kuznetsov S.O. Pattern Structures and Their Projections // ICCS 2001, LNCS 2120, 129–142, [doi:10.1007/3-540-44583-8_10](https://doi.org/10.1007/3-540-44583-8_10); Kaytoue M., Kuznetsov S.O., Napoli A., Duplessis S. Mining gene expression data with pattern structures in FCA // Information Sciences 181(10) (2011) 1989–2001, [doi:10.1016/j.ins.2010.07.007](https://doi.org/10.1016/j.ins.2010.07.007).

**Как объяснить кластеры (протокол):**
1. Шкалирование: каждый признак разбить на 3–4 квантильных интервала («доля продуктов — верхний квартиль») и добавить категориальные признаки: федеральный округ, тип МО (городской округ или район), численность. Получится контекст на ~2000 МО × 40–60 признаков.
2. Для кластера $k$ найти понятия $(A,B)$ с высокой точностью $|A\cap C_k|/|A|\ge0{,}9$, покрытием $|A\cap C_k|/|C_k|$ и устойчивостью $\sigma$. Это классификационные «гипотезы» в духе ДСМ-метода, которые Кузнецов переносил в FCA: Kuznetsov S.O. Machine Learning and Formal Concept Analysis // ICFCA 2004, LNCS 2961, 287–312, [doi:10.1007/978-3-540-24651-0_25](https://doi.org/10.1007/978-3-540-24651-0_25).
3. В отчёт для каждого кластера пойдут 2–3 содержания $B$ с точностью, покрытием и устойчивостью. Например: «Кластер 3 = {продукты: верхний квартиль, общепит: нижний квартиль, мобильность: низкая}, точность 0,93, покрытие 0,71, σ=0,88». Это и есть «кластер как тип местной экономики», с проверяемыми числами.
4. Динамика: для МО, сменивших кластер, показать, какой атрибут содержания изменился. Переход при этом объясняется одним-двумя сдвигами признаков.

**Библиотеки:** [`concepts`](https://github.com/xflr6/concepts) (MIT) — малые контексты и решётки; [`fcapy`](https://github.com/EgorDudyrev/fcapy) (GPL-3.0; автор Е. Дудырев из группы Кузнецова в ВШЭ) — контексты, решётки, узорные структуры; [`caspailleur`](https://github.com/EgorDudyrev/caspailleur) и [`paspailleur`](https://github.com/EgorDudyrev/paspailleur) (GPL-3.0) — поиск кратких представлений и узорных структур. Решётка на 2000 объектах может быть огромной. Её строить не надо: нужны только понятия с высокой точностью для каждого кластера, а их можно искать жадно (начать с признака, у которого лучший lift, и добавлять признаки, пока растёт точность). Затем проверить замкнутость через $B''=B$ и посчитать $\sigma$ методом Монте-Карло по подмножествам.

## 4. Как сравнивать кластеры во времени

**Подход 1. Сопоставление меток соседних месяцев** (минимум, без него нельзя).
Матрица пересечений $n_{ab}=|C^{t}_a\cap C^{t+1}_b|$ или Жаккара $J_{ab}=\frac{|C^t_a\cap C^{t+1}_b|}{|C^t_a\cup C^{t+1}_b|}$. Перенумеровать метки венгерским алгоритмом (`scipy.optimize.linear_sum_assignment(-J)`). Согласие между месяцами — ARI и AMI (`sklearn.metrics.adjusted_rand_score`, `adjusted_mutual_info_score`). Для AMI источник: Vinh N.X., Epps J., Bailey J. // JMLR 11 (2010) 2837–2854, [ссылка](https://jmlr.org/papers/v11/vinh10a.html); почему нужна поправка на случайность — Romano S. et al. // JMLR 17 (2016), [ссылка](https://jmlr.csail.mit.edu/papers/volume17/15-627/15-627).

**Подход 2. События жизни кластеров: MONIC и отслеживание сообществ.**
- MONIC: Spiliopoulou M., Ntoutsi I., Theodoridis Y., Schult R. MONIC: modeling and monitoring cluster transitions // KDD 2006, 706–711, [doi:10.1145/1150402.1150491](https://doi.org/10.1145/1150402.1150491). Кластер $X$ месяца $t$ «переживает» в $Y$ месяца $t+1$, если $|X\cap Y|/|X|\ge\tau$ ($\tau=0{,}5$). Внешние переходы: выживание, **распад** (несколько $Y$, каждый с долей $\ge\tau_{split}$, в сумме $\ge\tau$), **поглощение** (несколько $X$ попадают в один $Y$), исчезновение, появление. Внутренние переходы: изменение размера, компактности, сдвиг центра.
- Greene D., Doyle D., Cunningham P. Tracking the Evolution of Communities in Dynamic Social Networks // ASONAM 2010, [doi:10.1109/ASONAM.2010.17](https://doi.org/10.1109/ASONAM.2010.17). Динамические сообщества — цепочки по Жаккару $\ge\theta$ ($\theta\approx0{,}3$). События: рождение, смерть, слияние, разделение, продолжение.

На выходе таблица событий по месяцам и **аллювиальная диаграмма**: Rosvall M., Bergstrom C.T. Mapping change in large networks // PLoS ONE 5(1) (2010) e8694, [doi:10.1371/journal.pone.0008694](https://doi.org/10.1371/journal.pone.0008694). Для 10% за визуализацию: аллювий, связанный с картой, — клик по потоку подсвечивает МО.

**Подход 3. Согласованное разбиение сразу по всем месяцам** (вместо сопоставления задним числом).
- Многослойная модулярность: Mucha P.J. et al. Community structure in time-dependent, multiscale, and multiplex networks // Science 328 (2010) 876–878, [doi:10.1126/science.1184819](https://doi.org/10.1126/science.1184819). Каждый месяц — слой, узел связан сам с собой в соседних месяцах с весом $\omega$. Реализация: `leidenalg.find_partition_temporal` ([leidenalg](https://github.com/vtraag/leidenalg), GPL-3.0). Метки сквозные, а переход МО виден как смена сообщества при данном $\omega$. Кривая «число переходов от $\omega$» — это анализ чувствительности.
- Эволюционная кластеризация: Chakrabarti D., Kumar R., Tomkins A. Evolutionary clustering // KDD 2006, [doi:10.1145/1150402.1150467](https://doi.org/10.1145/1150402.1150467). Стоимость = качество снимка + $\alpha\cdot$ расхождение с прошлым. Самый ленивый вариант — k-means или KEFRiN с тёплым стартом от центров прошлого месяца.

**Индексы устойчивости** (чтобы отличить настоящий переход от шума):
- бутстрэп-устойчивость кластера — средний Жаккар кластера с лучшим совпадением на бутстрэп-выборках; меньше 0,6 — неустойчив. Hennig C. Cluster-wise assessment of cluster stability // CSDA 52(1) (2007) 258–271, [doi:10.1016/j.csda.2006.11.025](https://doi.org/10.1016/j.csda.2006.11.025);
- устойчивость выбора $K$: Lange T., Roth V., Braun M.L., Buhmann J.M. Stability-based validation of clustering solutions // Neural Computation 16(6) (2004) 1299–1323, [doi:10.1162/089976604773717621](https://doi.org/10.1162/089976604773717621);
- для МО — доля месяцев в своём модальном кластере; для системы — ARI между соседними месяцами против ARI между двумя бутстрэпами одного месяца. Переход засчитывается, только если он держится не меньше 2–3 месяцев и превышает шумовой уровень (оценка: так отсекаются сезонность и шум).

| Сеть и атрибуты (15%) | Узел — МО. Ребро — косинусное сходство векторов долей трат по категориям, kNN с $k=10$–15, симметризация. Абляция: корреляция помесячных рядов, DTW по 12-месячному окну, слой потоков мобильности. Для каждого варианта Q, AVI и доля изолятов. Имена типов давать после чисел. YAML с гиперпараметрами, seed, закреплённые коммиты чужих репозиториев, `make reproduce`. |
| Визуализация (10%) | Карта МО по кластерам с ползунком месяца + аллювий переходов + «паспорт типа» (профиль и FCA-описание) + параллельные координаты паттернов OIPC. Всё связано кликом. |
